# The Tech Hub — Front-End Web Application

A responsive multi-page **ASP.NET Core Razor Pages** web application designed to connect Oklahoma State University MSIS students, alumni, and industry employers with department resources and space utilization data.

## Tech Stack
* **Framework:** ASP.NET Core Razor Pages
* **Front-End:** HTML5, Custom CSS3 (`site.css`), Bootstrap 5
* **Typography & Design:** Google Fonts (`_Layout.cshtml`), 60/30/10 Color Architecture, Mobile-First Responsive Layout (Desktop & iPhone 16 viewports)
* **IDE:** Visual Studio

## Key Features
* **Custom Navigation & Full-Viewport Hero Banner:** Intuitive multi-page routing and custom brand styling with zero inline or embedded CSS.
* **Interactive UI Components:** 4-image Bootstrap 5 carousel, embedded Spears School of Business media, and a multi-column informational footer.
* **Space Utilization Dashboard:** Home page visual analytics component tracking student usage of The Tech Hub facility.
* **Dedicated Student & Employer Portals:** Tailored layouts showcasing collaborative workspaces, cybersecurity lab resources, and employer networking channels.
